# NewAOE fire particle Web demo

This target runs the shipping `RenderEngine` and `ParticleSystem` code. The
particle directory is generated by the same `ParticleSystemEditor` executable
used by the GUI:

```powershell
build-engine-mingw/bin/ParticleSystemEditor.exe --offscreen preset fire fire --force --json
build-engine-mingw/bin/ParticleSystemEditor.exe --offscreen set fire material.baseTexture fire.png --json
```

`NEWAOE_FIRE_ASSET_DIR` may point to any directory containing `particle.json`.
The native build copies that directory beside the executable; the Web build
preloads it into Emscripten's virtual filesystem at `/assets/fire`.

## Web (WSL Emscripten)

```bash
cd /mnt/c/QtHomeWork/NewAOE
emcmake cmake -S . -B build/sokol-fire-web \
  -DAOE_BUILD_WEB_FIRE_DEMO=ON \
  -DCMAKE_BUILD_TYPE=Release \
  -DNEWAOE_FIRE_ASSET_DIR=/mnt/c/QtHomeWork/NewAOE/fire
cmake --build build/sokol-fire-web --parallel 4
python3 Server/render/game/engine/WebFireDemo/serve.py build/sokol-fire-web/bin
```

Open `http://127.0.0.1:8125/SokolFireDemo.html`.

Controls: `Space` pauses/resumes, `R` restarts, and `Escape` exits on desktop.
